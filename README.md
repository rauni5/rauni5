## 🚀 Featured Projects

### 🎯 SkillPath: Career Learning and Collaboration Platform
Cross-platform mobile app where learners set career goals, track skills and follow personalized learning roadmaps, backed by a layered Spring Boot REST API deployed on AWS.

- Progress dashboard and gamified achievements
- Roadmap generation, skill checks, project collaboration with discussions and notifications
- Admin panel for managing the learning catalog
- Firebase Authentication with a backend token filter for secure, role-based access
- Supabase Storage for profile image uploads

**Stack:** Flutter · Dart · Java · Spring Boot · REST · Firebase Auth · Gemini API · Supabase · AWS · SQL

 **Repositories:** [Mobile app (Flutter)](https://github.com/rauni5/skillpath_app) · [Backend (Spring Boot)](https://github.com/rauni5/SkillPath-Backend)

### 🎬 [Cinosphere-Production](https://github.com/rauni5/Cinosphere-Production): Cinema Management System
Originally a group academic project built with JSP and Servlets. I forked it and independently migrated it into a decoupled **Spring Boot REST API + React** architecture.

- Authentication with role-based access control
- Movie, showtime and cinema management
- Ticket booking with seat selection
- Admin dashboard
- Dockerized setup

**Stack:** Java · Spring Boot · JPA/Hibernate · MySQL · React · Docker
· Legacy version: [legacy-servlet branch](https://github.com/rauni5/Cinosphere-Production/tree/legacy-servlet)

### 💬 [React Chat Application](https://github.com/rauni5/React)
A chat interface built to practise component architecture, props, state management and event handling with React and Vite.
